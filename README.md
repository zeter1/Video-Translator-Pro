# Video Translator Pro

**Video Translator Pro** — Windows-приложение для автоматического распознавания речи, перевода и озвучивания видео. Проект объединяет OpenAI Whisper, машинный перевод, Edge TTS / gTTS и FFmpeg в один устойчивый медиаконвейер.

Главная особенность проекта — режим **Pause Sync**: если перевод получается длиннее исходной фразы, программа старается сохранить естественную речь вместо агрессивного ускорения или обрезки перевода.

## Что демонстрирует проект

- построение многоэтапного медиапайплайна: audio extraction → speech recognition → translation → TTS → video assembly;
- работу с Whisper, Edge TTS, gTTS, FFmpeg и FFprobe в одном desktop-приложении;
- устойчивость длительных задач через checkpoints, recovery и повторное использование промежуточных результатов;
- контролируемые retry-стратегии и защиту от каскадных сетевых сбоев;
- проверку итогового артефакта, а не только успешный return code отдельной команды;
- проектирование алгоритма синхронизации, который балансирует длительность перевода и естественность речи;
- компактную структурированную диагностику для сложных проблем внешних сервисов и медиапроцессов.

## Основные возможности

- распознавание речи через OpenAI Whisper;
- перевод текста через `deep-translator` / Google Translator;
- нейросетевая озвучка через Edge TTS;
- резервный переход на gTTS;
- режим Pause Sync для длинных переведённых фраз;
- настраиваемый предел ускорения голоса;
- полный медиапайплайн FFmpeg / FFprobe;
- подмешивание оригинальной дорожки на фоне;
- перевод на несколько языков;
- постоянный TTS-кэш;
- checkpoint/recovery для незавершённых переводов;
- проверка итогового MP4 перед успешным завершением;
- структурированные диагностические сессии.

## Установка

1. Установите Python 3.10–3.13 для Windows.
2. Установите FFmpeg и FFprobe и добавьте их в `PATH` либо положите `ffmpeg.exe` и `ffprobe.exe` рядом с `video_translator.py`.
3. Скачайте проект через **Code → Download ZIP** или Git:

```bash
git clone https://github.com/zeter1/Video-Translator-Pro.git
cd Video-Translator-Pro
```

4. Создайте виртуальное окружение и установите зависимости:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install --upgrade pip
py -m pip install -r requirements.txt
```

При первом использовании Whisper может загрузить выбранную модель.

## Запуск

```powershell
py video_translator.py
```

Также можно использовать `Запустить.bat`.

## Как пользоваться

1. Запустите программу.
2. Выберите исходный видеофайл.
3. Укажите язык исходной речи и язык перевода.
4. Выберите настройки Whisper и TTS.
5. При необходимости настройте максимальное ускорение речи и подмешивание оригинального звука.
6. Запустите перевод.
7. Программа извлечёт аудио, распознает речь, переведёт текст, создаст озвучку и соберёт итоговое видео через FFmpeg.
8. После завершения программа проверит наличие видео- и аудиопотоков в итоговом MP4.

Если процесс был прерван, не удаляйте данные восстановления и TTS-кэш: при следующем запуске часть уже выполненной работы может быть использована повторно.

## Как работает Pause Sync

1. Используется доступная естественная пауза после исходной реплики.
2. При необходимости перевод умеренно ускоряется в пределах выбранного лимита.
3. Если фраза всё ещё не помещается, видеоряд временно останавливается, пока перевод не закончится.

Итоговый ролик иногда может стать немного длиннее оригинала, зато перевод не приходится резко обрезать или превращать в неестественно быструю речь.

## Диагностика

Логи разделяют обычные события, предупреждения и ошибки, группируют повторяющиеся сбои и сохраняют traceback и контекст настоящих ошибок. Это помогает разбирать проблемы Whisper, TTS, FFmpeg и сетевых сервисов без огромных повторяющихся журналов.

## Проверка кода

```powershell
python -m py_compile video_translator.py
```

GitHub Actions выполняет эту лёгкую проверку без загрузки Whisper-моделей и полного запуска медиапайплайна.

## Важные ограничения

- качество перевода зависит от качества распознавания речи;
- сильно заглушённые слова могут быть пропущены Whisper;
- Edge TTS требует сетевого доступа;
- полноценная проверка всего процесса требует реального Windows-окружения и FFmpeg.
