# Изменения Windows-сборки

- Опубликована актуальная модульная версия Video Translator Pro с постоянной очередью задач: можно добавлять следующие видео во время обработки, а незавершённую задачу продолжить после перезапуска.
- Добавлены локальные и гибридные маршруты перевода и озвучки: MarianMT, Argos и Piper с автоматическим переходом к доступным альтернативам. Модели и голоса устанавливаются отдельно; они не включены в EXE.
- Сохранены улучшения качества: подсказки Whisper из glossary, SRT рядом с готовым MP4, приглушение исходной речи во время русского голоса и Pause Sync.
- Исправлены совпадающие идентификаторы задач при быстром добавлении нескольких видео; очередь больше не путает такие задачи.
- EXE собирается из актуальных исходников с обязательными Python-зависимостями, локальными AI-библиотеками, FFmpeg и ffprobe. Перед выпуском workflow выполняет regression suite и проверку импортов и медиатулов внутри собранного EXE.
- Рядом с EXE публикуется SHA-256 для проверки скачанного файла.

## Проверка

Локально `python tools/verify_project.py`: 304 теста, 18 пропущены. GitHub Actions дополнительно проверяет сборку и packaged self-test на Windows перед созданием релиза. Реальный перевод видео, сетевые сервисы, загрузка моделей и аппаратное ускорение требуют проверки в пользовательской среде.
