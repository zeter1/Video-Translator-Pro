# Изменения Windows-сборки

## Новое в версии 2026.10.14.18

- **Исправлена работа Whisper на CUDA:** распознавание использует FP32 вместо FP16. Это предотвращает наблюдавшийся сбой `Categorical logits contain nan on cuda:0` на NVIDIA GTX 1660 SUPER; вычисления по-прежнему идут на GPU, а не принудительно переключаются на CPU.
- **Улучшена диагностика:** сводка качества распознавания теперь показывает вычислительную точность (FP32) и отсутствие FP16.
- **Тесты:** добавлены четыре offline regression-теста для GPU-режима Whisper, сохранения временных меток и текста при разбивке на части, отмены задания между частями и правильной передачи ошибок модели.
- **Совместимость:** прежние возможности перевода, озвучивания, восстановления заданий и постоянных уведомлений сохранены. Конфигурация и формат пользовательских данных не менялись.
- **Особенность FP32:** вычисления могут занимать больше видеопамяти, чем FP16; скорость зависит от GPU и доступной VRAM.

### Проверка текущей сборки

- Исходники версии `2026.10.14.18` прошли Windows GitHub Actions: установка зависимостей, компиляция и offline regression suite — **PASS**.
- Сборочный pipeline отдельно повторяет тесты и собирает Windows x64 `Video-Translator-Pro.exe` в режиме PyInstaller `--onefile` с включёнными FFmpeg и ffprobe.
- EXE публикуется только после успешного `--self-test` готового файла; в Assets релиза прилагается `Video-Translator-Pro.sha256.txt`.
- Полный перевод реального пользовательского видео и совместимость с каждым компьютером Windows требуют отдельной проверки.

## Улучшения предыдущей версии 2026.10.11.17
- **Постоянные уведомления о завершении задач:** отдельное немодальное окно справа внизу экрана, поверх обычных окон и над панелью задач Windows.
- **Быстрый доступ к результатам:** кнопка «Открыть папку» у каждого завершённого перевода открывает именно его папку с готовыми файлами; сообщение остаётся доступным после открытия.
- **Несколько уведомлений сразу:** сообщения накапливаются в прокручиваемом списке, закрываются индивидуально крестиком и не исчезают по таймеру.
- **Жизненный цикл окна:** уведомления видны при сворачивании основного окна, уничтожаются вместе с приложением. При недоступной папке результатов выводится понятная ошибка.
- **Тесты:** добавлены регрессионные проверки уведомлений и уточнены проверки очереди задач; обновлены архитектурная карта и README (RU/EN).
- **Совместимость CI:** тест открытия папки проверяет один и тот же каталог даже при разном написании Windows-путей (короткие имена 8.3 и полные пути).

## Остальные улучшения

- Папка готовых видео теперь содержит только итоговые видео. Служебный отчёт сегментов и SRT-файлы сохраняются во внутренней папке `translated_texts`, а не рядом с MP4.
- Улучшена отмена перевода: Whisper обрабатывает аудио ограниченными порциями и регулярно проверяет запрос отмены, поэтому длинное распознавание больше не блокирует остановку всей задачи до конца ролика.
- Если исходная речь подтверждённо русская и целевой язык — русский, программа не запускает перевод, TTS и пересборку: исходное видео безопасно перемещается в папку готовых видео с сохранением исходного контейнера.
- Исправлен шум в диагностике при отсутствии локального маршрута перевода: pipeline больше не пытается безуспешно запускать локальный перевод для каждого сегмента и сразу использует предусмотренный online fallback.
- Сохранены постоянная очередь задач, recovery после перезапуска, hybrid/local перевод и озвучка через MarianMT, Argos и Piper, glossary-подсказки Whisper, Pause Sync и приглушение исходной речи.
- EXE собирается с обязательными Python-зависимостями, локальными AI-библиотеками, FFmpeg и ffprobe. Перед публикацией workflow повторно запускает compile, regression suite и packaged self-test.
- Рядом с EXE публикуется SHA-256 для проверки скачанного файла.

## Проверка

- Для исходной версии `2026.10.11.17` ранее выполнен локальный `tools/verify_project.py`: **316 тестов, 18 пропущены, PASS**; проведён отдельный smoke-test Tk/Win32 уведомлений.
- При этой публикации GitHub Actions повторно выполняет установку зависимостей, компиляцию и regression tests в Windows runner, затем собирает однофайловый EXE через PyInstaller.
- Готовый `Video-Translator-Pro.exe` должен пройти `--self-test` с включёнными FFmpeg/ffprobe. При успехе публикуются EXE и SHA-256. До окончания workflow результат сборки считается непроверенным.
- Реальная обработка конкретного пользовательского видео и запуск EXE на других версиях Windows требуют дополнительной проверки.

## Установка

Скачайте `Video-Translator-Pro.exe` из Assets этого релиза и запустите в Windows. Python, FFmpeg и ffprobe включены в собранный EXE. Модели Whisper, локальные переводчики и голоса загружаются или устанавливаются отдельно через вкладку программы. Для сетевого перевода и озвучки требуется интернет. Бинарник не подписан коммерческим сертификатом, поэтому SmartScreen может показать предупреждение.
