# Поддержка и диагностика

Если Video Translator Pro не завершает перевод или создаёт некорректный результат, используйте GitHub Issue **Сообщить об ошибке**.

## Что указать

- commit/версию программы и Windows;
- этап сбоя: извлечение аудио, Whisper, перевод, Edge TTS/gTTS, Pause Sync, FFmpeg, финальная проверка или recovery;
- язык, модель Whisper, голос TTS, лимит ускорения и настройки оригинальной дорожки;
- версии FFmpeg/FFprobe;
- точные шаги воспроизведения;
- безопасный фрагмент диагностической сессии.

Если проблема связана с незавершённой задачей, не удаляйте recovery/checkpoint и TTS-cache до окончания диагностики.

## Проверка проекта

```powershell
python -m compileall -q video_translator.py videotranslator tests tools
python -m unittest discover -s tests -v
```

Regression-тесты рассчитаны на проверку программных контрактов без реального скачивания Whisper-модели или обращения к TTS/translation сервисам. Полный end-to-end перевод требует Windows, FFmpeg и доступных внешних сервисов.

## Приватность

Исходное видео, распознанный/переведённый текст, пути к файлам и диагностические материалы могут содержать личные данные. Не публикуйте их без предварительной проверки. Дополнительные рекомендации находятся в [`SECURITY.md`](SECURITY.md).
