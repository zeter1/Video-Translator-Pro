# Hybrid AI v8 — локальный перевод + точечный Google Repair

## Что реализовано

Hybrid AI v8 больше не является набором заглушек: локальные переводчики и локальная озвучка подключены к основному `VideoTranslator` pipeline.

Основная схема перевода:

```text
Whisper -> определение языка -> локальный перевод -> проверка качества
                                      |                 |
                                      |                 +-> всё нормально -> дальше
                                      |
                                      +-> подозрительный сегмент -> Google Repair только этого сегмента
```

Google Translate больше не обязан переводить каждый сегмент. Если локальный движок дал пригодный перевод, сетевого запроса нет. Если локальный результат выглядит неполным/почти неизменённым, в Google отправляется целый проблемный сегмент, а не отдельное слово без контекста.

## Локальные переводчики

В отдельной вкладке **«Переводчики и голоса»** доступны:

| Компонент | Назначение | Примерная загрузка | Примерно на диске |
|---|---|---:|---:|
| Argos Translate EN→RU | быстрый офлайн-перевод | ~187 МБ языковой пакет | до ~500 МБ с зависимостями |
| MarianMT OPUS EN→RU | более тяжёлый EN→RU офлайн-перевод | ~315 МБ | ~380 МБ |

Для английского программа предпочитает установленный MarianMT, затем Argos. Для других языков Argos может автоматически установить нужную языковую пару после того, как Whisper определил язык, **если сам Argos уже установлен и пользователь оставил включённой соответствующую настройку**.

Большие движки не устанавливаются молча во время обработки видео. Их установка запускается пользователем во вкладке моделей. Это не блокирует обычный Google-only режим, если локальные компоненты ещё не установлены.

## Как определяется, что нужен Google Repair

После локального перевода проверяется несколько признаков:

- пустой или подозрительно короткий результат;
- почти полное совпадение с исходным текстом;
- заметный остаток обычных слов исходного языка в EN→RU переводе;
- при этом распространённые технические термины (`API`, `Python`, `Docker`, `FFmpeg`, `GitHub` и т.п.) не считаются ошибкой сами по себе.

Если Google Repair временно недоступен, но локальный перевод существует, программа сохраняет локальный вариант вместо того, чтобы потерять весь файл.

## Защита от Google 429 на всей пачке

Состояние недоступности Google теперь общее для всей пакетной обработки, а не создаётся заново для каждого видео.

При rate-limit/сетевом шторме:

1. новые Google-запросы ограничиваются общим cooldown/circuit breaker;
2. поштучный retry-storm не запускается;
3. локальный перевод может продолжать работу без Google;
4. уже готовый прогресс остаётся в checkpoint;
5. диагностический журнал фиксирует причину, сегменты, failure class и recovery action.

Это устраняет сценарий, когда несколько следующих видео зря проходят дорогой Whisper только затем, чтобы снова упереться в тот же 429 на полном Google-переводе.

## Локальные голоса

В каталог добавлены хорошие русские Piper medium голоса:

| Голос | Примерная загрузка | Примерно на диске |
|---|---:|---:|
| Piper Дмитрий | ~63.3 МБ | ~64 МБ |
| Piper Денис | ~63.3 МБ | ~64 МБ |
| Piper Ирина | ~63.3 МБ | ~64 МБ |
| Piper Руслан | ~63.3 МБ | ~64 МБ |

Piper Engine устанавливается отдельно (~34.1 МБ загрузки; рабочий размер зависит от Python-окружения).

TTS fallback теперь выглядит так:

```text
Edge TTS
  -> при сетевом сбое: установленный локальный Piper
  -> если Piper недоступен/не подходит: существующий recovery/gTTS fallback
```

Выбранный локальный Piper-голос хранится в настройках. Локальный Piper используется до gTTS, поэтому сетевой шторм Edge больше не обязан превращаться в длинную цепочку сетевых повторов.

## Тайм-аут gTTS

В gTTS теперь явно передаётся `(connect timeout, read timeout)`. Это исправляет наблюдавшийся сценарий, где исключение показывало `connect timeout=None`, несмотря на общие сетевые настройки программы.

## Менеджер моделей

Вкладка **«Переводчики и голоса»** показывает до установки:

- название и тип компонента;
- качество/назначение;
- примерный объём загрузки;
- примерное место на диске;
- состояние установки и целостности;
- лицензионную/справочную пометку.

Доступны действия:

```text
[Установить] [Удалить] [Проверить] [Обновить] [Обновить список]
```

Перед крупной загрузкой программа показывает размер и требует подтверждение. Проверяется свободное место с резервом, а Piper voice ONNX проверяется по SHA-256.

## Что НЕ устанавливается автоматически

Windows Language Pack не нужен для Whisper, Argos, MarianMT, Edge TTS, gTTS или Piper, поэтому программа не пытается ставить системные языки Windows и не требует ради этого права администратора.

Опциональные AI-компоненты перечислены в `requirements-optional-ai.txt`; обычный `requirements.txt` остаётся компактным.

## Диагностика

Добавлены отдельные события гибридного контура: локальный backend, причина Google Repair, shared cooldown/rate-limit и локальный TTS fallback. Старые события rate-limit сохранены для совместимости диагностических отчётов и regression-тестов.
