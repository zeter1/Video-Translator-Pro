# Терминологический словарь

Файл `translation_glossary.json` задаёт желательные соответствия `исходный термин -> русский вариант`.

Пример:

```json
{
  "OpenAI Whisper": "OpenAI Whisper",
  "graphics processing unit": "графический процессор",
  "John Smith": "Джон Смит"
}
```

В архиве есть безопасный шаблон `translation_glossary.example.json`. Скопируйте его как `translation_glossary.json` и замените примеры своими терминами.

## Как словарь используется

1. До распознавания **только исходные термины** попадают в короткую подсказку Whisper. Это помогает именам, названиям продуктов и техническим словам распознаваться стабильнее.
2. Для длинного видео подсказка переносится на следующие внутренние окна Whisper, если установленная версия это поддерживает.
3. После машинного перевода программа делает только точечную очистку: русский вариант подставляется, если исходный термин был в исходной реплике и этот же термин остался непереведённым в результате.
4. Ручные правки в окне проверки выполняются после автоматической очистки, поэтому пользователь остаётся последней инстанцией перед TTS.

## Где хранится файл

- В обычной portable-папке с правом записи: рядом с программой.
- В защищённой установке, где каталог программы недоступен для записи: runtime root пользователя (`%LOCALAPPDATA%\\VideoTranslatorPRO` по умолчанию).
- Переменная `VIDEO_TRANSLATOR_RUNTIME_DIR` может явно задать runtime root.

Словарь должен быть корректным JSON-объектом. Пустые ключи/значения игнорируются; повреждённый JSON сохраняется резервной `*.corrupt.*.json` копией перед будущей перезаписью.
